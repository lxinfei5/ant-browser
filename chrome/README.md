# Browser Core Placeholder

Place downloaded **official Chromium / Chrome for Testing / Google Chrome** cores under this directory when running from source.

- Preferred download source in the app: [Chrome for Testing](https://googlechromelabs.github.io/chrome-for-testing/)
- fingerprint-chromium is **not** used or recommended

Published macOS and Linux packages include this placeholder only. Actual browser core binaries are user-managed and should live under the writable `chrome/` directory in the runtime state root.
